# dataset/ — исходный датасет KolobanovEye 2.0

Эта папка находится **внутри проекта**. Её содержимое, кроме этого README, полностью исключено из Git.

Генератор создаёт **один сырой датасет за запуск**. Никаких train/val/test, сплиттера и релизов на данном этапе нет.

```text
KolobanovEye/
  dataset/
    README.md                    # отслеживается Git
    raw/                         # актуальный завершённый датасет, Git игнорирует
      images/                    # все кадры вместе, без папок карт
        00000001.png
        00000002.png
      annotations/
        instances.json           # один COCO для всех карт и кадров
      metadata/
        images.jsonl             # полная информация для каждого кадра
        scenes.jsonl             # сцены и привязка кадров
        maps.json                # карта и доступные координаты танкового поля
        generation_config.json   # параметры без личных локальных путей
      manifest.json              # фактическое количество изображений, карт, аннотаций
    runs/                        # диагностика, логи, промежуточные результаты Dagor
      run-YYYYMMDDTHHMMSSZ-XXXXXXXX/
        runs/avg_карта/...       # исходные технические кадры по картам
        coco/                    # временный технический объединённый COCO
        multi-manifest.json
```

## Обновление raw

При нажатии «Создать и проверить датасет» в GUI запускается новый технический прогон. В случае существующего `dataset/raw` GUI **спрашивает подтверждение замены**.

- До полной генерации и проверки предыдущий `raw` не изменяется.
- Новый `raw` собирается во временном каталоге с проверкой соответствия COCO и PNG.
- Только после успешной проверки папка `raw` заменяется новой. Если публикация не удалась, старая папка восстанавливается.
- При успешной замене прежний `raw` удаляется, но каталоги `runs/` остаются: они могут занимать много места и предназначены для ручной диагностики/очистки.
- Для экономии места изображения в `raw` обычно создаются жёсткими ссылками на проверенные кадры в `runs/`, а если это невозможно — копируются. Удаление технических `runs/` не удалит уже созданные PNG в `raw/`.

## Запуск без GUI

```powershell
python .\ke_dataset.py --config .\config.example.json
# Для подтверждённой замены уже существующего raw:
python .\ke_dataset.py --config .\config.example.json --replace-raw
```

Экспорт и разделение датасета на train/val/test **не входят в данный этап**.
