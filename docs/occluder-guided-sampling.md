## 2.9.1 — первый рабочий срез исходного кода

Опция `guided_sampling`: off (по умолчанию) / obstacle.
Требуются AVF и ранее подготовленный кэш умной расстановки 2.7, включая
objects.jsonl. Не требуется повторный скан карты при наличии этих файлов.

Для целей light/moderate/heavy: локальный пространственный индекс
уникальных объектов, выбор потенциальных углов AABB и камеры на дальней
стороне границы; до двух направленных колец с низкими допустимыми высотами,
с сохранением широких ракурсов. Open оставляет исходный банк. Предложения
позиции танка переупорядочиваются по достижимым препятствиям, каждая пятая
позиция сохраняет старый порядок. Ни один предложенный танк не считается
физически допустимым без текущей native проверки.

Python публикует неизменяемый банк ракурсов для каждого кандидата размещения.
Dagor использует банк фактически выбранного placement_candidate, а Python
проверяет индекс и guided_camera_plan; сохраняются выбранные банки в плане
и метаданные guided_sampling. При попадании внутрь целевого диапазона
с запасом от границ возможна досрочная остановка после группы GPU.
Окончательное решение по видимости/COCO — только существующие полные маски.

AABB — грубый приоритет, не доказательство реального перекрытия. Скан 2.7
не гарантирует полноту статической геометрии. Положение камеры внутри
сложных объектов ещё не проверяется точной геометрией. Нативная компиляция
и результат Windows не подтверждены. Добавлены Python-тесты и CI-триггер.

## 2.9.2 — предварительная отбраковка (код реализован)

Новая опция `guided_prerender`: off (по умолчанию) / conservative.
Требуется obstacle. Фильтр не кредитует квоты: он только пропускает
полный рендер. Разрешение на отказ публикует Python для текущей карты
и запроса, если ячейка open насыщена до min(глобальная квота open,
квота карты), open не входит в полезные следующие категории и текущая
цель не open. Каждая пятая попытка карты исключена из фильтра.
Native принимает разрешение только при >=8 валидных пробах,
без невалидных среди выполненных, с минимумом видимости >=98%.
Неизвестные пробы никогда не повод отбрасывать кадр.
Если проверенный полный кадр на карте показывает не-open при AVF>=98%,
фильтр автоматически отключается для этой карты до конца запуска.

Отказ redundant_open_probe записывается в KEFRAME и подтверждается ready
без PNG/масок, учитывается в общем лимите кандидатов и отдельно от
геометрических отказов, ошибок глубины и стабильности. При итоговой
сверке проверяются причина, количество проб, индекс расстановки, цель,
разрешение и отсутствие файлов. Квоты, полные маски и COCO неизменны.
Manifest/visibility-quotas фиксируют guided_prerender_rejections,
guided_prerender_probes и guided_prerender_disabled_maps. В benchmark
добавлен явный флаг --compare-guided для сравнения разных режимов.

Приёмка после реализации этапа: A/B/C — off/off, obstacle/off,
obstacle/conservative с одинаковым seed и всеми остальными настройками.
Сопоставить полный wall time, число дорогих рендеров, число проб с учётом
отказов, точность масок и успешность строгих квот. Фильтр может не
сработать на карте, где open ещё полезен или AVF нестабилен; это штатно.
Тесты Python добавлены, не запущены здесь; Windows сборка и тест не проверены.
