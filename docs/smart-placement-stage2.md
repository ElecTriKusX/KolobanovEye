текстуры — maps/. dataset/raw не изменяется.

Сканирование по тайлам <=128 м с ожиданием подготовки RI; владение по
корневой позиции исключает дубли между тайлами. Геометрический обход
обычных RI без обращения к отсутствующим игровым props, отдельно RIExtra
через валидные handle каждого пула, включая без коллизии. Полнота стриминга
пока не доказана; пустой тайл не означает отсутствие геометрии. Статическая
геометрия SCol/FRT пока не перечисляется; деревья/дома по имени ресурса —
эвристика, не классы ML. 16 м ячейки, плотность по корням (логарифмическая
шкала на карту), группы — 8-связные занятые ячейки AABB. Границы AABB
консервативны, не точный контур коллизии. Без обзорной текстуры — явный
однотонный фон и отметка в отчёте. Никакого RGB/масок танка.

До Windows-проверки не подключать к выбору позиций. Следующие шаги 2.7:

## V2: фильтрация, классификация, локальные группы

Исходные TSV и все записи JSONL остаются; raw bbox_ids и center_ids не
фильтруются. analysis_layer — эвристика имени и высоты/ширины render AABB;
collision_only, water_surface, detail, linear не участвуют в оценке
визуальной плотности, но остаются в пространственном индексе. Точные
совпадения (source/layer/pool/resource/root/bbox/collision) помечаются
 duplicate_of и не увеличивают аналитическую плотность; это не удаление
реальных экземпляров. Категории: building, rock, vegetation, small, unknown.
16 м ячейки, 4×4 подячейки; для каждой категории берётся максимум площади
пересечения AABB с подячейкой, не сумма, чтобы не раздувать вклад
наложенных деталей. AABB для оценки ограничен 32 м (building/rock) или
16 м (остальные), исходный bbox не меняется. Score 0..1 одинаков на всех
картах; общая плотность — максимум по слоям. Это приближение, не точная
площадь объединения и не прозрачность/физическая проходимость.
Группы: 4-связные ячейки корней отдельно по категории и внутри сектора
128×128 м. Границы сектора намеренно разрезают крупные леса/кварталы;
это локальные группы для будущего выбора позиций, а не семантические районы.
Индекс v2: layer_scores, density, groups_by_layer; прежний scalar group
заменён. Карты: objects-map (корни), density-map, groups-map,
large-obstacles-map, vegetation-map, small-obstacles-map,
unknown-obstacles-map, low-density-map (density <= 0.1; не карта разрешённой
расстановки). Для пересчёта --recover-run с исходным native batch и PNG.
Реальная проверка build_index по 166432 JSONL: Factory 15950 пригодных
для оценки, 1249 групп, max 291; Town 27837, 6014, max 340; Falklands
32436, 1509, max 798; Finland 22841, 1298, max 273. 204 точных повтора.
Полнота RendInst и корректность коллизий не доказаны; статическая сцена
не выгружена. Сама генерация кадров пока не использует этот индекс.

## V3: предварительный банк точек для синтетической генерации

Сетка 8 м, отступ 5.5 м от краёв и исходных коллизионных render AABB
в XZ (объекты высотой >= 0.9 м). Консервативное предварительное
исключение, не доказательство свободного объёма. Приближённые полосы
по расстоянию до ближайшего визуального препятствия: open >=24 м,
light 14..24, moderate 9..14, heavy <9. Эти полосы не являются
измеренной видимостью. Файл placement-candidates.json (версия, map id,
границы, SHA256 исходного TSV, точки по полосам) и карта
placement-candidates-map.png. Точки не проверены по высоте/воде/коллизиям.
Детерминированный выбор 75% из запрошенной/ближайшей полосы, остальные
для исследования; явный uniform fallback при исчерпании банка.
Офлайн на всех четырёх старых выгрузках: 443841 точек сетки, 234641
потенциальных; Factory 48997, Town 131380, Falklands 29609, Finland 24655.
