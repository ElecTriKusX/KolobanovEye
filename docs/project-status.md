# KolobanovEye 2.0. Состояние по полному ТЗ

Основание: «KolobanovEye 2.0 — техническое задание для Codex», разделы 1–15. Базовая ветка `annotation-generator` включает PR #2 с адаптивным прогревом. Подтверждение Windows для 40 кадров относится к `fix/resolve-white-haze`. Позы Tiger H1 проверены на Windows в PR #3. Лог от 17 ноября 2026 фиксирует успешную сборку Dagor с ooz и шесть кадров с разными углами при seed 42. Валидатор, аудит рельефа, экспорт COCO и создание шести превью завершились успешно. Пользователь подтвердил корректность изображений. Повтор полного набора Python-тестов на Windows после исправления подготовки CRLF-фикстуры ожидается.

## Текущий этап: avg-карты и танковый квадрат (18 ноября 2026)

- Ветка: `feature/avg-map-catalog-whitelist`, от `main`.
- Пользователь подтвердил на Windows работу автоматического обнаружения `avg_*.bin`, интерфейса whitelist и первых тестов (этапы 1–2).
- В ветке реализованы, **но ещё не приняты на Windows**: одиночный выбор активной карты, `--level`, запись `map_id`, отдельный Dagor-патч доступа к `tankMapCoord0/1`, JSON с границами танкового поля и режим нормализованной расстановки `tank_map`.
- Многокартовая серия с равными квотами ещё **не реализована** (есть только проверенная чистая функция квот). Прямой рендер обзорной текстуры танкового квадрата через `render_last_clip_in_box` тоже **не реализован**; диагностический `last_clip` всего ландшафта оставлен отдельно.
- Для приёмки новой работы нужны повторная сборка Dagor с патчем, полные Python-тесты и RGB-проверка Normandy + одной дополнительной `avg_*.bin`; результаты сверить с `tank-map-bounds.json` и `metadata.jsonl`.
- Детальные критерии и команды: `docs/map-catalog-roadmap.md`. Ограничения других подсистем из таблицы ТЗ остаются актуальными.
